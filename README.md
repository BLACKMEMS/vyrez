# Вырез: вырезка по точкам на телефоне

Android-приложение для Samsung S25 Ultra (и любого Android 10+, 64 бит). Всё считается на самом телефоне, интернет не нужен.

## Как пользоваться
1. **Видео**: выбрать ролик из галереи (или «Поделиться → Вырез» прямо из Галереи).
2. Режим **＋ Оставить**: тап по тому, что оставить. Зелёная заливка показывает, что выделилось.
3. Режим **－ Убрать**: тап по лишнему, что прилипло к объекту.
4. Несколько людей или предметов: **+ объект**, у каждого свои точки. «виден с кадра» / «до кадра» ограничивают, когда объект в кадре.
5. **Проверить трекинг**: прогон по всему видео без сборки. Листайте шкалу: синяя маска = что получится. Где ошиблось, поставьте точки на этом кадре и проверьте снова.
6. **Обработать**: готовое видео сохраняется в Галерею, папка `Movies/Vyrez`.
7. **⚙**: фон (зелёный, свой цвет, размытие, картинка), край уже/шире, точность, размер, звук.

Двумя пальцами: зум и сдвиг кадра, кнопка **⤢** сбрасывает зум. **◀• / •▶**: прыжок к кадрам с точками. Точки запоминаются для каждого видео.

## Как получить APK (один раз, минут 10)
1. Зарегистрируйтесь на github.com (бесплатно).
2. Справа вверху **+ → New repository**, имя например `vyrez`, тип **Public** (у Private тоже работает, но ограничены бесплатные минуты), **Create repository**.
3. На странице репозитория: **uploading an existing file**. Распакуйте архив на ПК и перетащите **содержимое** папки `VyrezPhone` (включая папку `.github`) в окно браузера → **Commit changes**.
   Или через git в папке проекта:
   ```
   git init
   git add .
   git commit -m "first"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/vyrez.git
   git push -u origin main
   ```
4. Вкладка **Actions**: сборка запустится сама, ждите зелёную галочку (5–8 минут).
5. На телефоне откройте `https://github.com/ВАШ_ЛОГИН/vyrez/releases/latest` и скачайте `vyrez.apk`.
6. Установите. Samsung попросит разрешить установку из браузера: «Настройки → Разрешить из этого источника».

Если сборка упала с красным крестиком: откройте её, нажмите на шаг «Сборка», скопируйте последние строки ошибки и пришлите.

Новые версии ставятся поверх старой (ключ подписи `app/release.jks` лежит в проекте, не удаляйте его).

## Как это устроено
- Нейросеть: Google MediaPipe Magic Touch (выделение предмета по точке), на видеокарте телефона.
- Трекинг: на каждом кадре предмет выделяется заново, точки едут вслед за ним; кадры с вашими точками задают их заново. До первого кадра с точками считается назад.
- Сборка: аппаратный кодировщик H.264 телефона, звук копируется из исходника без перекодирования.
